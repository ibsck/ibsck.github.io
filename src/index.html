Comment je travaille

Les mêmes étapes, quel que soit le projet.

  1. Comprendre le besoin

    J’échange avec les utilisateurs métier et les équipes techniques pour cerner les règles avant de développer. Pendant mon stage au CNAM, j’ai rédigé le cahier des charges.

  2. Concevoir

    Modélisation des données, architecture hexagonale et DDD, pour que les règles métier restent lisibles et faciles à faire évoluer.

  3. Développer en équipe

    Tests avec PHPUnit, revue de code par Merge Requests, organisation Agile/Scrum.

  4. Livrer

    Docker, GitLab CI/CD, Nginx, Ansible. Exemple : le référentiel RID 2025 intégré en production sans interruption de service.

  5. Documenter et maintenir

    Documentation pour les utilisateurs, maintenance corrective et évolutive dans la durée.
